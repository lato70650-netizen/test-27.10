## Лендинг Ганг Люкс — искусство вождения

Адаптивный статический сайт на HTML и CSS. Сборка и зависимости не требуются.

Локальный запуск из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

## Бесплатная публикация

Для GitHub Free репозиторий должен быть публичным. В Settings → Pages выберите
Deploy from a branch, ветку `main` и каталог `/ (root)`, затем Save.
После успешного развёртывания адрес: https://lato70650-netizen.github.io/test-27.10/

Обновления сайта публикуются после отправки изменений в `main`.
Демонстрационная концепция премиальной автошколы в синей палитре.
Изображения в `assets/` созданы с помощью ИИ и не показывают реальный автопарк.
Город: Москва. Услуги: обучение с нуля, восстановление навыков, персональный инструктор.
По запросу владельца контакты, формы и кнопки записи отсутствуют.
Тексты сайта находятся в `index.html`, оформление — в `styles.css`.
