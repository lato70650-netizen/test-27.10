# Помощник команды

Worker для поиска по утверждённым карточкам Notion и ответов в Telegram и веб-интерфейсе.

**Статус:** приглашения реализованы и проверены локально. Для запуска необходимо создать D1 для доступа, настроить и проверить реальные интеграции. Не разворачивать без этой настройки.

Владелец создаёт одноразовые ссылки на странице `/manage`. Приглашения действуют 24 часа; веб-сессия — 30 дней. Максимум пять веб-сессий и пять Telegram-доступов отдельно. Две ссылки нужны для двух каналов. Секрет владельца `ADMIN_SECRET` задаётся как секрет Worker, не менее 32 случайных символов. Имя бота задаётся переменной `TELEGRAM_BOT_USERNAME`. База D1 хранит сведения доступа, а утверждённые ответы — только Notion.

D1 binding должен называться `ACCESS_DB`, схему создаёт `migrations/0001_invitations.sql`. При отсутствии базы доступ по умолчанию закрыт. Идентификатор Notion и данные о реальных подключениях настраиваются отдельно в Cloudflare. Токены, ссылки-приглашения и секреты не добавлять в репозиторий.

Локальное демо: `npm ci`, `cp .dev.vars.example .dev.vars`, `npm run dev`. Проверки: `npm test` и `npm run check`.
