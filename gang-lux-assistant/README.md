# Помощник команды

Предварительная версия Worker для поиска по утверждённым карточкам Notion и ответов в Telegram и веб-интерфейсе.

**Статус:** приглашения для сотрудников ещё не реализованы. Не разворачивать для реального использования до реализации и проверки доступа, интеграций и настроек.

Для локального демо: `npm ci`, `cp .dev.vars.example .dev.vars`, `npm run dev`. Тесты: `npm test`.

Секреты и идентификаторы подключаются через настройки Worker; не помещайте их значения в репозиторий.
