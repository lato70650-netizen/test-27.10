# Помощник команды

Worker для ответов из утверждённых карточек Notion через веб и Telegram. Сотрудники используют одну общую ссылку, которую передаёт владелец.

**Статус:** общий вход проверен локально. Продакшн не настроен; необходимы D1 для данных доступа и проверка живых интеграций. Ссылка многократная: любой её получатель сможет войти. Смена ключа владельца закроет все старые доступы и создаст новую ссылку.

Владелец получает ссылку на странице `/manage`, используя секрет `ADMIN_SECRET` длиной не менее 32 случайных символов. `TELEGRAM_BOT_USERNAME` — имя бота без @. D1 binding `ACCESS_DB` должен быть создан и настроен отдельно; схему создаёт `migrations/0001_shared_access.sql`. В D1 хранятся автоматически зарегистрированные Telegram ID, карточки и ответы — только в Notion. При отсутствии D1 доступ закрыт.

Идентификаторы и секреты настраиваются отдельно; их нельзя помещать в публичный репозиторий. Для локального демо: `npm ci`, `cp .dev.vars.example .dev.vars`, `npm run dev`. Проверки: `npm test` и `npm run check`.
