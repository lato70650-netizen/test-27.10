# Помощник команды

Worker отвечает из утверждённых карточек Notion через закрытый веб и личный чат Telegram. Владелец добавляет сотрудников в закрытую группу, а бот автоматически проверяет участие перед каждым ответом. Бот должен быть администратором группы; ручной список и база сотрудников не нужны.

Владелец выдаёт одну общую ссылку для веба. Любой её получатель может войти. Смена `ADMIN_SECRET` закрывает старую ссылку и веб-сессии. Для получения ссылки используется `/manage`.

Настройки: секреты `ADMIN_SECRET`, `NOTION_TOKEN`, `OPENROUTER_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`; переменные `NOTION_DATA_SOURCE_ID`, `TELEGRAM_GROUP_ID` и `TELEGRAM_BOT_USERNAME`. Ключ владельца — не менее 32 случайных символов. `keep_vars` сохраняет параметры dashboard; реальные секреты, ссылки и идентификаторы приватных ресурсов в Git не добавляются.

Информация хранится только в Notion. Тесты: `npm test`; сборка без публикации: `npm run check`. Реальную работу и права бота в группе нужно проверить отдельно.
